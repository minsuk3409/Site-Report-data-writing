# 보건 점검관리 화면 시안

녹색 강조색을 사용한 기존 단일 HTML 시안에서 복원한 웹사이트 소스입니다. 네 종류의 점검을 등록·검토하고 공통 보고서로 정리하는 화면 흐름을 확인할 수 있습니다.

- 안전보건심사
- 안전보건심층진단
- 온열질환 모니터링
- 한랭질환 모니터링

## 실행

`index.html`을 브라우저에서 직접 열거나, 저장소 폴더에서 다음 명령으로 실행합니다. 웹사이트 실행에는 Node.js 패키지 설치가 필요하지 않습니다.

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

브라우저 주소: `http://127.0.0.1:8765`

## 소스와 단일 HTML

| 파일 | 용도 |
| --- | --- |
| `index.html` | 화면 기본 구조 및 시작 페이지 |
| `styles.css` | 기존 시안의 시각 디자인과 반응형 레이아웃 |
| `app.js` | 대시보드·목록·등록·분석 검토·보고서·공통 양식 화면 동작 |
| `docs/health-inspection-preview.html` | 내려받아 실행할 수 있는 단일 HTML |
| `docs/previews/` | 기존 시안 화면 이미지 |

수정할 때는 루트의 HTML·CSS·JavaScript를 편집하고 아래 명령으로 단일 HTML을 생성합니다. 생성된 HTML을 직접 수정하면 동기화 검사에서 검출됩니다.

```sh
npm run build
npm run check
```

복원 시점의 단일 HTML은 기존 파일과 바이트 단위로 일치합니다. 시각 디자인과 가상 데이터를 유지했습니다.

## 검수

Node.js 20 이상에서 브라우저 검수를 실행할 수 있습니다.

```sh
npm ci
npx playwright install chromium
npm test
```

검수 범위는 PC·모바일의 6개 화면, 점검 종류·목록 필터, 파일 형식 검증, 원문 대조 확인, 보고서 편집·미리보기·다운로드, 화면 오류 및 외부 통신 여부입니다.

시스템 Chromium을 사용하는 경우 `PLAYWRIGHT_CHROMIUM_EXECUTABLE` 환경변수로 브라우저 실행 파일을 지정할 수 있습니다.

## 구현 범위

모든 현장·점검·분석 결과는 가상 예시입니다. 파일은 이름과 형식만 확인하며 내용 판독·전송·AI 분석·서버 저장은 구현되어 있지 않습니다. 편집 내용은 현재 화면 세션의 메모리에만 유지되며 새로고침 시 사라집니다. 실제 HWP·PDF 출력은 별도 구현이 필요합니다.

GitHub Pages를 사용하는 경우 배포 브랜치의 루트 폴더를 시작 위치로 지정할 수 있습니다. 현재 작업은 소스 업로드이며, Pages 배포 설정은 포함하지 않습니다.
